# Contributing to EA 4-Class Spiral Optimization

Thank you for your interest in contributing to this research project!

## 🎯 Project Scope

This repository contains the implementation of a peer-reviewed IEEE EIT 2025 paper. While the core research is complete, we welcome:

- Bug fixes
- Code improvements and optimizations
- Documentation enhancements
- Additional visualization features
- Performance benchmarks

## 🛠️ How to Contribute

### 1. Report Issues
- Use GitHub Issues for bug reports
- Include error messages and system information
- Describe steps to reproduce the problem

### 2. Suggest Enhancements
- Open an issue with your idea
- Explain the use case and expected benefit
- Discuss before implementing major changes

### 3. Submit Pull Requests

**Process:**
```bash
# Fork the repository
# Clone your fork
git clone https://github.com/YOUR_USERNAME/EA_4Class_Spiral_optimizing.git

# Create a feature branch
git checkout -b feature/your-improvement

# Make your changes
# Add tests if applicable

# Commit with clear messages
git commit -m "Add: brief description of changes"

# Push to your fork
git push origin feature/your-improvement

# Open a Pull Request on GitHub
```

## 📝 Code Guidelines

### Python Style
- Follow PEP 8 conventions
- Use meaningful variable names
- Add docstrings to functions
- Include inline comments for complex logic

### Documentation
- Update README if adding features
- Document new functions thoroughly
- Include usage examples

### Testing
- Ensure code runs without errors
- Test with the provided dataset
- Verify results are reproducible

## ✅ Pull Request Checklist

Before submitting:
- [ ] Code follows PEP 8 style guidelines
- [ ] All functions have docstrings
- [ ] README updated if needed
- [ ] No unnecessary files included
- [ ] Changes are well-tested
- [ ] Commit messages are clear

## 🤝 Code of Conduct

- Be respectful and professional
- Provide constructive feedback
- Focus on improving the project
- Help maintain code quality

## 📧 Questions?

Contact the author:
- Email: schurakan@ltu.edu
- Open a GitHub issue for technical questions

Thank you for contributing to advancing evolutionary deep learning research! 🚀
